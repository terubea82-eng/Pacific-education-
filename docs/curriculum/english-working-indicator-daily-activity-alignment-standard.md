# PacEdu English — Working Achievement Indicator to Daily Activity Alignment Standard

**Approved planning basis:** 19 November 2026. The owner has directed PacEdu to use the learning concepts in `english-corrected-concepts-ece-form-7.md` as PacEdu working achievement indicators for English activity design.

## 1. Meaning of a working achievement indicator

For this programme, each concept is converted into a learner-centred, observable statement describing what the learner can demonstrate. The indicator is a PacEdu planning and assessment tool. It is not represented as verbatim Ministry wording or an official Ministry indicator code.

Use this construction:

**Learner can + observable action + relevant English content/text/context + expected evidence.**

Avoid vague verbs such as *know*, *understand* or *learn* unless the activity also identifies what the learner will do to demonstrate that knowledge.

## 2. Daily alignment requirements

Every daily activity must show:

1. **Working achievement indicator:** one observable outcome derived from that level's concept progression.
2. **Daily learning focus:** the specific skill practised that day.
3. **Activity:** what the teacher and learner do to practise the indicator.
4. **Worked example:** a real, level-appropriate example showing the steps and expected response.
5. **Copper/Bronze/Silver/Gold:** four scaffolded versions of the same indicator and objective; do not change the learning goal.
6. **Evidence / success check:** what the teacher can see, hear, read or otherwise observe.
7. **Answer / marking guidance:** acceptable responses, equivalent wording and evidence criteria.
8. **Next step:** reteach, practise, consolidate or extend based on evidence.

The weekly concept provides the shared direction. The daily indicator narrows it to one assessable step. Do not copy the same broad weekly objective into all five daily indicator fields.

## 4. Differentiation rule

All four pathways pursue the same indicator.

- **Copper:** model the response; reduce the number of steps; use accessible text, tactile/visual support, choices and supported communication.
- **Bronze:** provide one worked example, prompts, a word bank or planning frame; gradually reduce help.
- **Silver:** complete the target with minimal prompts and independently check the response.
- **Gold:** deepen the same target through more precise evidence, comparison, explanation, independent choice or revision.

Do not make Gold a different syllabus objective or make Copper a different, permanently lower curriculum. Adapt the access route and degree of independence.

## 5. Assessment and marking

- Assess the skill named by the indicator, not the learner's accent, disability-related speech differences or preferred communication mode.
- Accept accurate synonyms, equivalent wording and supported alternative interpretations.
- For comprehension and critical literacy, require relevant evidence where the indicator calls for it.
- Use A/B/C/D multiple-choice items only where a multiple-choice check is appropriate; include constructed, oral, signed, AAC, pointing, drawing or written responses when those better assess the target.
- Record evidence and the next teaching step. Do not treat worksheet completion alone as proof of achievement.

## 6. Ministry alignment remains a separate field

Each activity retains two distinct labels:

- **PacEdu working achievement indicator:** approved for PacEdu planning by the owner.
- **Official Ministry source alignment:** pending until the current authorised syllabus/guide, edition, exact official outcome/indicator, page and reviewer are recorded.

This distinction does not prevent PacEdu from using the working indicators to build and teach the activities. It prevents an unverified PacEdu concept from being misrepresented as an official Ministry quotation.

## 7. Completion checks

A level is ready for educator review only when its 115 daily activities each have a specific working indicator, activity, worked example, four matched pathway tasks, observable evidence and marking guidance. Its 460 worksheet versions must match the same daily indicators and not drift into unrelated objectives. A level is not cleared for learner release until a Fiji-qualified educator reviews the content and the school's current curriculum pathway is checked.
