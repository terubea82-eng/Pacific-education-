# PacEdu English Subject Box — Consolidated Workbook and Class Structure

**Scope:** ECE, Classes 1–8, Forms 1–7 (16 levels)  
**Pathways:** Copper, Bronze, Silver, Gold  
**Status:** Documentation staging only — no live app integration, merge, deployment or APK change.

## Consolidated master download

The current consolidated reference workbook is stored in the PacEdu Library:

`/PacEdu/English/PacEdu_English_Consolidated_Master_Workbook_ECE_to_Form7.docx`

It combines the existing ECE–Form 7 Week 1 starter pack, Forms 1–2 Week 1 pathway worksheets, ECE and Class 3 Week 2 pathway batches, and a completion/release checklist. It also identifies additional Class 1–4 packs retained in the repository.

**Important:** The master workbook is a consolidation of material found, not a completed 115-day annual worksheet programme. Missing days are not represented as complete.

## Locked class/day subject-box structure

Use this structure for every class/form:

`English → [Class/Form] → Term → Week → Day`

Each daily entry must contain:
- Copper learner worksheet — separate download
- Bronze learner worksheet — separate download
- Silver learner worksheet — separate download
- Gold learner worksheet — separate download
- Copper teacher marking guide — separate teacher-only file
- Bronze teacher marking guide — separate teacher-only file
- Silver teacher marking guide — separate teacher-only file
- Gold teacher marking guide — separate teacher-only file

The consolidated master workbook is an additional all-level reference. It does not replace these class/day pathway downloads.

## Release safeguards

- Keep teacher marking guides separate from learner downloads.
- Every learner file must be standalone: learner identification, class, subject, term/week/day, ability pathway, complete reading passage/instructions, worked example, questions and generous response spaces.
- All four pathways work toward the same objective, with differentiated scaffolding and extension.
- Use only A/B/C/D for multiple-choice items where MCQ is suitable.
- Keep `PENDING_TEACHER_REVIEW` and `PENDING_INDICATOR_VERIFICATION` until the relevant checks are complete.
- Verify exact Fiji curriculum source, edition/year, page and indicator wording before claiming official alignment.
- Never assign a permanent ability label from one worksheet or inaccessible/unanswered item.
