# PacEdu Teacher-Only Marking Guide — Class 1 English
## Week 3 · Days 11–15 · Gold pathway

**Matched learner worksheet:** class-1-english-week-03-gold-days-11-15.md
**Learning intention:** Analyse and follow spoken directions, compare position words, and compose clear safe directions.

**Fair marking:** Accept spoken, signed, AAC, drawn, dictated or written responses. Assess meaning and clarity, not accent or handwriting.

| Code | Meaning |
|---|---|
| I | Independent |
| P | With visual/gesture prompt |
| M | After adult model |
| NYO | Not yet observed |

### Day 11 — Analyse
1. MOVE; PENCIL; UNDER.
2. PUT; RULER; IN.
3. Position is given by UNDER / IN respectively.

### Day 12 — Compare
- ON means above/touching the top surface.
- UNDER means below.
- Accept two directions using the same object and distinct, correctly used position words.
- Explanation should state that changing the position word changes where the object goes.

### Day 13 — Sequence
1. First pick up ruler; next put it beside pencil.
2. First open bag; next put book inside.
3. Credit explanation that order tells the listener what to do first and next.

### Day 14 — Create and test
- Accept a safe, two-step direction using familiar objects.
- Partner result is recorded without blaming the listener; revise unclear words if needed.

### Day 15 — Review
1. PLACE; PENCIL; UNDER.
2. Example repair: First pick up the book. Next put it in the bag.
3. Accept a clear two-step direction and accurate explanation of a key word.
