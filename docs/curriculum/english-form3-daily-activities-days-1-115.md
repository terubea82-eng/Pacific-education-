# PacEdu English Subject Box — Form 3 Daily Activities (Days 1–115)
**Status:** ORIGINAL PACEDU DRAFT — PENDING_TEACHER_REVIEW — PENDING_OFFICIAL_INDICATOR_VERIFICATION. Not an official Fiji Ministry scheme. No official indicator IDs, exact wording, source pages or approved sequence are claimed.
23 planning weeks × 5 days = 115 activities. Term 1: Weeks 1–9; Term 2: Weeks 10–18; Term 3: Weeks 19–23. Four differentiated pathways (Copper/Bronze/Silver/Gold) share the same learning objective. For Forms 3–4, the public Revised Secondary English Curriculum teacher-guide description uses Language, Text Types and Critical Literacy strands; school must verify current authorised guide, implementation and page-level outcomes. Do not infer official indicator codes.

## Daily learning activities

### Day 1 — Term 1, Week 1 — Identity, voice and community — Listening and speaking
**Objective:** Explore narrative voice, audience and context; close-read a text; create coherent paragraphs.
**Teacher-led activity:** Listen actively, contribute to discussion and ask a purposeful follow-up question. Use an authorised level-appropriate text or prompt connected to the theme. Learners identify the task and audience, gather ideas and communicate a reasoned response.
**Worked example:** Model task interpretation → identify key idea → select text evidence → organise response → review language for audience and purpose. Teacher models with the current class text.
**Copper:** Model each step; chunk the task; use accessible short text, visual/tactile cues, a word bank and guided choices. Accept speech, sign, AAC, pointing, gesture, dictation or writing.
**Bronze:** Provide a worked example, planning frame, vocabulary bank and guided prompts; reduce support gradually.
**Silver:** Complete the shared objective independently; organise ideas, select relevant evidence and review the response.
**Gold:** Extend the same objective with a nuanced interpretation, comparison, counter-view or independent revision; do not change the objective.
**Evidence:** Record an observable response (discussion contribution, vocabulary choice, evidence-based inference, critical observation, draft/revision or presentation). Accept appropriate communication modes.
**Answer guidance:** Credit accurate responses supported by the text and taught content; accept equivalent wording and alternative interpretations supported by evidence.
**Official indicator:** PENDING_OFFICIAL_INDICATOR_VERIFICATION. Insert exact authorised outcome, edition and page only after checking the school guide. Review: PENDING_TEACHER_REVIEW.

**Teacher-led activity:** Analyse vocabulary, register and a language feature in context. Use an authorised level-appropriate text or prompt connected to the theme. Learners identify the task and audience, gather ideas and communicate a reasoned response.
**Worked example:** Model task interpretation → identify key idea → select text evidence → organise response → review language for audience and purpose. Teacher models with the current class text.
**Copper:** Model each step; chunk the task; use accessible short text, visual/tactile cues, a word bank and guided choices. Accept speech, sign, AAC, pointing, gesture, dictation or writing.
**Bronze:** Provide a worked example, planning frame, vocabulary bank and guided prompts; reduce support gradually.
**Silver:** Complete the shared objective independently; organise ideas, select relevant evidence and review the response.
**Gold:** Extend the same objective with a nuanced interpretation, comparison, counter-view or independent revision; do not change the objective.
