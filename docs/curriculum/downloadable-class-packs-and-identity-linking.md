# PacEdu dated downloadable learning packs

## Teacher workflow

The teacher workspace includes a downloadable pack builder for each supported class/level, subject, term and ability group. It prepares a local HTML file that can be saved, printed or opened and printed to PDF from the device browser.

- Terms 1 and 2: nine planned teaching weeks each (45 daily slots).
- Term 3: five planned teaching weeks (25 daily slots).
- Four differentiated groups: Support, Developing, Expected and Extension.
- The pack includes daily activity pages, answer/marking notes for teachers, a revision practice set, a mock practice examination label, suggested marking guidance, and the automatically generated preparation date.
- The date is the date the pack is generated. A school's calendar is required to populate actual lesson dates; the generator must not invent dates.
- Pack content is assembled from the existing PacEdu worksheet bank. Any unavailable activity is counted, not silently claimed to exist.

## Student evidence and identity

A saved response carries the activity/assignment reference, class/subject/term/day context, preparation date, and current learner identity verification status. The teacher review queue displays these details to help match evidence to the correct task.

Fiji FEMIS identity remains pending until an authorised school verification flow confirms it. The current registration screen deliberately does not retain an unverified raw FEMIS ID in browser storage. Do not claim that an unverified ID has been matched. The learnerReference shown by the pilot is not proof of a verified FEMIS identity.

Class-wide downloads must never contain a list of learner IDs or personal submissions. Individual student evidence belongs in the authorised review workflow.

## Marking criteria and safeguards

The packs include subject-oriented suggested criteria and differentiated support guidance. The current rubric is a draft scaffold, not a universal official Ministry rubric. Teachers must adapt it to the actual learning outcome and task, especially for ECE, practical, oral, performance, creative and open-ended work.

- Objective answers may be compared with an answer key only when the question and key have been reviewed.
- Open-ended work, camera images, handwriting, oral responses and practical demonstrations require confidence checks and/or teacher review.
- If a camera image is unreadable, the activity must be flagged for resubmission/manual review, not guessed.
- A single response must not set a learner's permanent ability group.
- Practice examination papers are generated study materials, not official or past examination papers.
- Achievement-indicator mappings remain NOT_YET_MAPPED until checked against a current authorised syllabus.

## Current limitations

The pack builder provides a downloadable class/ability pack in the teacher workspace. It does not yet verify FEMIS IDs against an authorised roster, create actual school calendar dates without calendar data, or guarantee that every class/subject bank is complete and officially mapped. Student access to daily activities remains subject to teacher approval and the existing workspace flow.
