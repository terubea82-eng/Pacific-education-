## Accessibility and teaching safeguards
- Accept oral, pointing, sign, AAC, dictated, drawn and written responses according to the skill being assessed. Do not score accent or disability-related speech differences as errors.
- Use only grapheme–phoneme correspondences and high-frequency words already taught in the school's approved sequence. Teacher must substitute a familiar taught example if an item is not yet taught.
- Copper–Gold are flexible scaffolds, not permanent labels. Learners may move between pathways based on evidence. Do not deny access to the shared class objective.
- Each day includes actual prompts/items and response space. Teachers may enlarge or adapt print layout for access needs.
