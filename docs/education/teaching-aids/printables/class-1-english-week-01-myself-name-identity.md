# PacEdu Class 1 English — Printable Teaching-Aid Pack
## Programme Week 1 · Days 1–5 · Myself, name and identity

**Status:** Draft printable master for teacher review. Original PacEdu material; not an official Ministry resource. Curriculum outcome/indicator remains `PENDING_VERIFICATION`. Use only after checking the school's approved Class 1 English sequence and learner access needs.

**Print/use:** Print at a size learners can access. Cut cards on the separators. Make tactile duplicates with safe, teacher-approved materials where needed. Describe every visual aloud; colour is never the only cue. Do not require photographs or private family details. Learners may use a chosen name, symbol, drawing, AAC, sign, pointing, dictation or writing.

**Shared learning intention:** A learner can recognise and communicate their chosen name and participate in a simple self-introduction.

**Teacher preparation:** Blank name cards; learner-approved letter tiles (copy the letters in each learner's name without teaching an untaught sound); mirror or optional self-portrait frame; pencils/markers; tactile/large-print alternatives; a safe choice of identity symbols. Confirm name spelling/pronunciation with the learner and family/school record as appropriate.

## Day 1 — Listen and notice: recognise my name

**Teacher model:** Show one teacher-prepared name card. Say/sign/communicate, “This is my name.” Point to the whole written name; do not require decoding.

**Aid 1A — Name card (complete one per learner)**

| MY NAME |
|---|
|  |
|  |

**Aid 1B — Name match cards (teacher writes the learner's name on both cards)**

| Card A | Card B |
|---|---|
|  |  |

**Learner task:** Find or select the card that matches their chosen name. The teacher may present two cards at a time and read/describe both.

**Worked example:** Teacher matches two identical teacher-prepared cards: “Mere” to “Mere”. Learner then matches their own two cards. Use the learner's correct chosen name; “Mere” is only an illustrative example.

**Copper:** Two-card choice; adult models; accept touch, gaze, pointing, sign, AAC or matching.  
**Bronze:** Two or three cards with a name cue; learner matches one independently after a model.  
**Silver:** Match own name among a small set of familiar names and explain/show the match.  
**Gold:** Match own name in a different print position or type size and explain the clue used; do not turn this into an untaught decoding test.

**Evidence:** Correct match, response mode and prompt level.

## Day 2 — Model and explore: build my name

**Teacher model:** Place the letters of a teacher-prepared name in order, pointing to each tile while saying, “I put the letters in the same order as my name card.” Do not teach a letter sound unless it is already in the approved sequence.

**Aid 2A — Letter-tile tray**

| Tile 1 | Tile 2 | Tile 3 | Tile 4 | Tile 5 | Tile 6 |
|---|---|---|---|---|---|
|  |  |  |  |  |  |

Add or remove spaces to match the learner's name. Prepare a duplicate set of the same letters for matching.

**Aid 2B — Build-and-check mat**

| MY NAME CARD |
|---|
|  |

| BUILD MY NAME HERE |
|---|
|  |
|  |
|  |

**Learner task:** Match or arrange the prepared letter tiles so they look the same as the learner's name card. If letter tiles are not accessible, use tactile letter forms, movable symbols, AAC or a teacher-scribed response.

**Worked example:** Put the letters M–e–r–e beside the model card “Mere”, checking the order from left to right. This is a visual matching example, not a prescribed spelling or phonics sequence.

**Copper:** Adult places one tile at a time; learner matches identical tiles.  
**Bronze:** Provide the correct tiles in a mixed, small set and a visible model.  
**Silver:** Arrange the learner's name from the prepared tiles with minimal prompting.  
**Gold:** Rebuild the same name after the model is briefly covered, then check against the card; do not penalise a learner for using an access method.

**Evidence:** Tile order compared with the learner's verified name card; prompt level.

## Day 3 — Practise together: names belong to people

**Teacher model:** Demonstrate taking turns: “My name is ____. What is your name?” Accept a response in the learner's chosen communication mode. Never force public speaking.

**Aid 3A — Turn-taking prompt cards**

**MY TURN**  
I share my chosen name.

---

**YOUR TURN**  
You may share your chosen name.

---

**LISTEN / LOOK / WAIT**  
Give the other person time to respond.

**Aid 3B — Name-to-person matching mat**

| NAME CARD | PERSON'S CHOSEN SYMBOL / DRAWING |
|---|---|
|  |  |
|  |  |
|  |  |

Use only learner-approved names and symbols. A learner may choose a neutral symbol or leave the second column blank.

**Learner task:** In a pair or small group, take turns matching a name card to its owner or chosen symbol. A learner may pass.

**Worked example:** Teacher matches their own name card to their own chosen symbol, then models waiting while a learner chooses whether to participate.

**Copper:** One-to-one adult-supported turn; learner may pass or point.  
**Bronze:** Use two familiar name cards and a turn-taking prompt.  
**Silver:** Complete two or more respectful turns and match a name card accurately.  
**Gold:** Explain how the group checked a match while respecting a learner who chooses not to share.

**Evidence:** Participation/choice, accurate match where attempted, and respect for turn-taking.

## Day 4 — Apply independently: make my name card

**Teacher model:** Make a name card from the learner's verified chosen name, checking spelling and layout with the learner.

**Learner task:** Create or select a finished name card using a preferred response mode. Add a learner-chosen drawing or symbol only if wanted.

**Worked example:** Teacher writes their own name on a card, checks it against their model and places it in a display sleeve. Learner then creates their own card with agreed support.

**Copper:** Select a prepared card or place matching tiles; adult may scribe.  
**Bronze:** Trace or copy from the model with a word/letter bank.  
**Silver:** Write or assemble the chosen name with minimal prompting.  
**Gold:** Create a second layout of the same name and check both against the verified model.

**Evidence:** Completed/selected name card and the response mode used.

## Day 5 — Review and demonstrate: my name portfolio item

**Teacher model:** Revisit the name card and letter-matching activity. Model checking one item against the original name card.

**Learner task:** Select one name card or name-building sample for the portfolio. Learner may communicate a reflection orally, by sign, AAC, pointing, drawing, dictation or writing.

**Worked example:** Teacher selects their own name card, compares it with the model and records one thing that helped. Learner chooses their own portfolio item.

**Copper:** Choose one completed item from two options; adult records the learner's selection.  
**Bronze:** Select an item and complete the reflection with a prompt card.  
**Silver:** Select and explain/show why the item represents their learning.  
**Gold:** Compare the first and final name card and identify one improvement or useful strategy.

**Evidence:** Portfolio item, learner choice, response mode, prompt level and next step.

## Reusable accessible prompt cards

**LOOK / FEEL / LISTEN** — Explore the card in your preferred way.

**MATCH** — Find the same name.

**BUILD** — Put the name tiles in the same order as the model.

**CHECK** — Compare your work with the name card.

**YOUR CHOICE** — You may speak, sign, point, use AAC, draw, dictate or write.
