# Pacific Education — AI Task Allocation and Completion Matrix

## Pilot-to-complete operating rule
Each AI performs only its allocated responsibility. A system may hand off work to another system through an explicit interface, but it must not silently take over another system's task. Human/authorized review remains required for formal academic, safeguarding, legal, curriculum and production decisions.

## Allocated systems

| System | Own task | Pilot status |
|---|---|---|
| Pacific Guardian | Security, access gating, threat quarantine, audit evidence | Implemented foundation |
| AI Workflow | Authorization, orchestration, human-review routing and audit | Implemented foundation |
| CAM Marking | Objective → criteria → evidence → suggested mark → feedback | Allocation registered; full rubric engine remains to be implemented/verified |
| Teacher Guide AI | Teacher preparation, instructions, examples, differentiation and marking guidance | Allocation registered; full feature remains to be implemented/verified |
| Essay Studio | Writing instruction, planning, scaffolding and revision | Allocation registered; full feature remains to be implemented/verified |
| Projects Studio | Proposal → research → plan → evidence → report → presentation → reflection → portfolio | Allocation registered; full feature remains to be implemented/verified |
| Accessibility Support | Multiple appropriate response modes and learner supports | Allocation registered; full feature remains to be implemented/verified |

## Handoff rules
1. Security concerns go to Pacific Guardian.
2. Authorized AI coordination goes through AI Workflow.
3. Academic marking suggestions go to CAM Marking.
4. Teacher-facing activity guidance goes to Teacher Guide AI.
5. Student writing support goes to Essay Studio.
6. Extended project support goes to Projects Studio.
7. Learner-access needs go to Accessibility Support.
8. Formal teacher decisions remain teacher/authorized-reviewer decisions.
9. Official Fiji curriculum claims require verified source mapping before production use.
10. Production eligibility remains fail-closed until all required independent gates are verified.

## Completion sequence
**Pilot:** connect and test each allocated task independently → record evidence → correct defects → controlled user testing.

**Production transition:** independently verify curriculum, security, privacy, safeguarding, accessibility, authentication/database, hosting, payments where applicable, legal requirements and owner approval → update release evidence → only then consider production release.
