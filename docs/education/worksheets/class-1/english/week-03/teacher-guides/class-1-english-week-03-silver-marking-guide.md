# PacEdu Teacher-Only Marking Guide — Class 1 English
## Week 3 · Days 11–15 · Silver pathway

**Matched learner worksheet:** class-1-english-week-03-silver-days-11-15.md
**Learning intention:** Identify action/object/position information and follow familiar two-step directions.

**Fair marking:** Accept demonstration, pointing, signing, AAC, drawing, dictation or writing. Do not score accent, speech clarity, reading or handwriting. Record prompt level.

| Code | Meaning |
|---|---|
| I | Independent |
| P | With visual/gesture prompt |
| M | After adult model |
| NYO | Not yet observed |

### Day 11 — Key words
1. Action PICK UP; object PENCIL.
2. Action CLOSE; object BAG.
3. Action POINT; object TABLE.
4. Accept the action word or an equivalent demonstration.

### Day 12 — Position words
- ON = on top of.
- BESIDE = next to.
- IN = inside.
- UNDER = below.
Credit the learner's demonstrated or described position.

### Day 13 — Sequence
1. Pick up pencil; put it on table.
2. Open book; point to first page.
3. Credit recognition that the first action enables or comes before the next action.

### Day 14 — Transfer
- Ruler placed below book.
- First close book; next put it in bag.
- Any safe, clear two-step direction earns credit if steps are ordered.

### Day 15 — Review
1. Action MOVE; object PENCIL; position BESIDE.
2. Correct order: pick up book (1), put book in bag (2).
3. Accept a safe, clear two-step direction with familiar objects.
