# Pacific Education — Next Phase Android / Google Play Readiness

## Current phase

**Controlled pilot Android build preparation.**

The repository contains a native Android wrapper that loads the controlled Pacific Education pilot from GitHub Pages. This is not production approval.

## Built in this phase

- Native Android project under `android/`
- Package: `fj.pacificeducation.app`
- Target/compile API 36
- Minimum API 24
- AGP 9.4.0
- Gradle 9.6
- JDK 17
- HTTPS-only WebView
- Cleartext traffic disabled
- File/content access disabled
- Mixed content disabled
- External URLs leave the WebView
- No signing key or payment credentials stored in the repository
- GitHub Actions debug APK build
- GitHub Actions unsigned release APK validation
- GitHub Actions unsigned release AAB validation

## Android release boundary

A Play-ready **signed AAB** is not generated by this repository workflow yet; the workflow now validates an unsigned AAB build. Signing must be performed with a protected keystore outside the repository or through secure signing infrastructure. 

Do not commit:
- keystore files
- passwords
- service-account private keys
- payment secrets
- production credentials
- real child personal information

## Next phase sequence

1. Confirm Android debug build succeeds.
2. Confirm unsigned release build succeeds.
3. Install and test the APK on representative Android devices.
4. Prepare the final app icon, screenshots and store listing copy.
5. Establish and publish the required privacy policy and data-safety information based on the actual production data flows.
6. Configure Google Play Console.
7. Produce and securely sign an Android App Bundle (AAB).
8. Start the required closed testing process for the developer account.
9. Record pilot feedback, defects, accessibility results and security/privacy findings.
10. Keep the production gate fail-closed until all required independent/authorized approvals are complete.

## Important

Google Play publication is an external process. A successful repository build does not itself mean the app is accepted, production-approved, or publicly released.

The Pacific Education production gate remains separate from the Android packaging pipeline.
