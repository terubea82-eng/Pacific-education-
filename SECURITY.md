# Pacific Education Security Policy

## Security status

Pacific Education is a controlled prototype pilot. It is not authorized for production use.

## Owner-controlled repository

The repository owner controls publication, release authorization, production approval, and ownership of the project. A collaborator or contributor does not receive ownership, equity, intellectual property rights, or production-release authority merely by having repository access.

## Do not submit sensitive data

Do not place passwords, API keys, payment credentials, real child records, exact child locations, or other confidential information in issues, pull requests, commits, or the prototype.

## Reporting a vulnerability

For a suspected security vulnerability, do not publish exploit details in a public issue. Contact the repository owner privately through an appropriate GitHub private reporting/security channel if enabled.

## Production boundary

GitHub Pages and browser JavaScript are not production authentication, authorization, database, payment verification, privacy, child-safeguarding, or cybersecurity controls. Production remains blocked until the required external controls and owner authorization are independently verified.

## Response

Security reports should be triaged, affected code isolated, credentials revoked/rotated when applicable, and fixes validated before release. Never treat a client-side control as proof of production authorization.
