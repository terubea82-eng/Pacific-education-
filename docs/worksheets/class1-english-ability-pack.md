# PacEdu worksheet pack — Class 1 English
**Status:** Original pilot learning material; not yet verified against the current official Fiji Ministry syllabus/achievement indicators.  
**Term plan:** Term 1, Week 1, Day 1 (editable by the teacher).  
**Learning goal:** Learners identify a person, read/listen to simple sentences, and answer questions using information in a short text.  
**Use:** Each ability group is a separate worksheet/download. Give a child the group supported by recent evidence in this subject; do not label a child permanently. The percentage bands are pilot guidelines, not a diagnosis.

## Worksheet A — Support (0–49%)
**Name/learner ID:** __________ **Date:** __________  
**Teacher:** __________ **Ability group:** Support  
**Learning goal:** Find a name and one object in a short sentence.

**Do this:** Listen to your teacher or use the audio button. Read the sentence. Circle or say the answer.

**Example:** “Mere has a bag.” Who has a bag? **Mere.**

**Read/listen:** “Jone has a red book.”

1. Who has a book?  
   ☐ Jone  ☐ Mere
2. What does Jone have?  
   ☐ a book  ☐ a ball
3. What colour is the book?  
   ☐ red  ☐ blue
4. Complete: “Jone has a ____.”  
   Word bank: **book / fish**

**Try by yourself:** Draw or choose a picture of a book.

**Teacher marking:** 1 mark each for Q1–Q4 (4 marks); Q4 accepts “book”. Picture task is participation evidence, not a literacy mark.  
**Next step:** If the learner answers with support, repeat with a new one-sentence text; reduce prompts gradually.

## Worksheet B — Developing (50–64%)
**Name/learner ID:** __________ **Date:** __________  
**Teacher:** __________ **Ability group:** Developing  
**Learning goal:** Find stated details in two simple sentences.

**Do this:** Read/listen. Tick or write the answer.

**Example:** “Ana has two pens. One pen is blue.” How many pens? **Two.**

**Read/listen:** “Samu walks to school with his sister. He carries a green bag.”

1. Who walks to school? __________
2. Who walks with Samu? __________
3. What colour is the bag? __________
4. Tick the correct sentence:  
   ☐ Samu carries a green bag.  
   ☐ Samu carries a red bag.
5. Write one word naming something you carry to school. __________

**Teacher marking:** 1 mark each (5 marks). Accept an oral answer for a learner who is being assessed orally, and record the response mode.  
**Next step:** Move to fewer prompts when the learner consistently finds details in new texts.

## Worksheet C — Expected (65–79%)
**Name/learner ID:** __________ **Date:** __________  
**Teacher:** __________ **Ability group:** Expected  
**Learning goal:** Answer detail questions and make a simple inference.

**Do this:** Read/listen twice if needed. Answer in a word or short sentence.

**Example:** “It is raining. Jo opens an umbrella.” Why does Jo open it? **To keep the rain off.**

**Read/listen:** “The class plants a bean seed in a pot. Ana waters it and puts it near sunlight. Every Friday, the class measures the plant.”

1. What does the class plant? __________
2. What two things does Ana do? __________
3. When does the class measure the plant? __________
4. Why does the class measure it each week? __________
5. Write one sentence about how to care for a plant. __________

**Teacher marking:** Q1=1, Q2=2 (both actions), Q3=1, Q4=1 for a sensible evidence-based reason, Q5=1 for a relevant sentence. Total 6.  
**Next step:** Ask the learner to explain an answer using a detail from the text.

## Worksheet D — Advanced (80–100%)
**Name/learner ID:** __________ **Date:** __________  
**Teacher:** __________ **Ability group:** Advanced  
**Learning goal:** Use text evidence, explain cause, and suggest a fair improvement.

**Do this:** Read carefully. Answer in complete sentences where asked.

**Example:** “The soil is dry, so Litia waters the plant.” What caused Litia to water it? **The soil was dry.**

**Read/listen:** “Class 1 planted two bean seeds in separate pots. Both pots received the same amount of water. Pot A was kept near sunlight; Pot B was kept in a dark cupboard. After one week, the class recorded each plant’s height.”

1. What did the class change between the two pots? __________
2. Name one thing the class kept the same. __________
3. Why is it useful to keep the water amount the same? __________
4. What should the class record before deciding which plant grew better? __________
5. The class repeats the test, but Pot B gets less water. Explain why this makes the sunlight comparison less fair. __________
6. Write a two-sentence conclusion using evidence the class would need to collect. Do not invent results. __________

**Teacher marking:** Q1=1; Q2=1; Q3=2 for fair comparison; Q4=1 for measured heights/observations; Q5=2 for identifying a second changed variable; Q6=2 for a cautious evidence-based conclusion. Total 9.  
**Next step:** Extend with a new short text and ask the learner to compare evidence, explain limitations, and justify a conclusion.

## Accessibility alternatives (same learning goal)
- **Blind/low-vision:** Supply a screen-reader-friendly text file and spoken directions; ensure audio can be replayed and stopped; offer braille/raised-letter cards or safe tactile objects where appropriate. Do not make color the only clue; name the colour aloud.
- **Deaf/hard-of-hearing:** Show the full written instructions and transcript; caption any video; use clear pictures/sequence cards and a sign-language video only where the learner's preferred sign language is known. Never make audio the only source of information.
- **Other access needs:** Allow pointing, typing, AAC, oral response, or a scribe where appropriate; note the response mode without lowering the learning goal automatically.

## Teacher quick guide
1. Select the learner's current evidence-based group for **English**; a learner may be in a different group in another subject.
2. Read the short instruction and show the worked example.
3. Let the learner attempt independently before giving a hint.
4. Record the score and the type of support used.
5. Use more than one task over time before changing a group. The 80% band is a pilot flag, not a permanent label.
6. Keep the answer key in the teacher view. Release the student worksheet only through the existing teacher approval flow.
