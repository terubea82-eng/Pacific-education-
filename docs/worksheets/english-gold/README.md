# English Gold worksheets — subject-box staging index

**Subject-box structure:** English → Class/Level → Gold → Day 001–115  
**Scope:** ECE, Classes 1–8 and Forms 3–7  
**Status:** Staging content only. Not merged into the live PacEdu app and not yet curriculum-verified.

Gold worksheets extend the approved learning objective for the same class/level; they must not teach higher-level content as a substitute. Each day is a standalone learner worksheet with identification fields, complete task/instructions, worked example, answer space for each response, and a separate teacher marking guide. The exact current Ministry indicator and authorized source must be recorded before marking curriculum alignment complete.
