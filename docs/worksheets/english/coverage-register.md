## Important quality distinctions

1. The all-level Week 1 starter pack covers all 16 levels but generally uses one common daily task with generic pathway scaffolds. It is not four fully independent learner worksheets for every day.
2. The ECE and Class 3 Week 2 batches have separate learner files for Copper, Bronze, Silver and Gold, but each batch currently has one shared teacher guide rather than four separate pathway-matched teacher guides.
3. The Forms 1–2 Week 1 batch has four separate learner files for each form, but one shared teacher guide rather than four separate pathway-matched guides per form.
4. Class 1–4 supplementary packs use older labels Support, Developing, Expected and Advanced. These correspond conceptually to Copper, Bronze, Silver and Gold for reference only. Their historical percentage ranges are not approved placement rules.
5. Exact official Fiji Ministry curriculum indicators, editions and page references remain to be verified. Existing draft labels must not be changed to curriculum-verified without evidence.
