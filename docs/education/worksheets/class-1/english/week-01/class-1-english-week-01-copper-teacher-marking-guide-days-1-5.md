### Learning intention
Learner recognises and communicates their chosen name and participates in a simple self-introduction using an accessible communication mode.

### Access and safeguarding
Use learner-chosen name and verified spelling. No photo or private family information required. Accept matching, placing tiles, gaze/pointing, sign, AAC, drawing, dictation, scribing or writing. Do not assess speech clarity, accent, hearing, handwriting, speed or untaught letter-sound knowledge. Learner may pass during social exchange. Record support and response mode. Pathway is an adjustable scaffold, not a fixed ability label.

### Materials
Learner-approved name card; duplicate matching card; prepared letter/symbol tiles; greeting/turn cards; portfolio sleeve; large-print/tactile/AAC alternatives. Check safe materials and accessible placement.

### Five-day teaching and evidence guide

| Day | Teacher model / task | Indicative evidence and marking |
|---|---|---|
| 1 | Present the learner's name model; match identical cards. | Accurate match or purposeful selection. Accept access method; record prompt level. |
| 2 | Arrange prepared tiles/symbols to match the name model. | Tile order matches model; do not mark phonics/spelling unless taught and intended. |
| 3 | Model HELLO / GOOD MORNING and respectful turn-taking. | Meaningful greeting/selection and turn; passing is respected and not penalised. |
| 4 | Make/select a name card; compare with verified model. | Card represents chosen name; record whether learner matched, assembled, dictated or selected. |
| 5 | Select portfolio item and communicate what helped. | Learner choice and accessible reflection; record next teaching step. |

### Pathway scaffold — Copper
Adult models each step; offer two choices; learner may match identical cards, point, gaze, sign, use AAC, dictate or select a prepared response. Keep one card visible at a time.

### Marking record
Use **I** = independent after instruction; **P** = prompt; **M** = model/support. Mark **E** = evidence observed, **S** = with support, **NO** = not observed (not a failure score).

| Skill | E / S / NO | Response mode / prompt |
|---|---|---|
| Recognises/matches chosen name | | |
| Assembles name from prepared model | | |
| Uses/chooses a greeting or turn | | |
| Checks own name card against model | | |
| Selects portfolio evidence | | |

### Indicative answers
- Day 1: the learner's own prepared name cards match exactly.
- Day 2: tile/symbol sequence matches that learner's verified name model.
- Day 3: any suitable greeting or accessible greeting-card selection; participation may be one turn or pass.
- Day 4: finished/selected card matches chosen name model.
- Day 5: any learner-selected item; reflection may be shown through any communication mode.

Accept equivalent correct wording and demonstration. Do not require “Mere”; it is only an example. If evidence is unclear, reteach with an accessible model and record what support helped.
